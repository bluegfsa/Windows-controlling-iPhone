# 03 · 命令参考

统一形态：`phone.cmd <子命令> [参数]`（Linux/macOS 用 `python phone.py ...`，本包只验证了 Windows）。
**所有命令输出一行 JSON**，成功 `"ok": true`、失败 `"ok": false` + `"error"` + `"hint"`，进程退出码 0/1。
每个响应都带 `"ms"`：本命令从启动到返回的总耗时（含 Python 启动 ~0.6 s）。

---

## 一、链路管理

### `status`
```jsonc
{"service": true, "wda": true, "app": "com.autonavi.amap",
 "screen": {"width": 390, "height": 844, "scale": 3, "pixel_width": 1170, "pixel_height": 2532},
 "ok": true, "ms": 812}
```
`wda:false` 时其余字段可能缺失。**这是每个任务的第一步**。

### `up` / `down`
`up` 幂等：热的时候 30 ms 返回；冷的时候自动走"服务→分离→进程内"三级降级（最长 ~150 s）。
`down` 拆掉隧道/转发/服务，返回 `{"stopped": true}`。

### `doctor`
11 项体检，返回 `{"checks":[{name, ok, detail, fix}...], "failing": N}`，有失败则退出码 1。
**排障永远先跑它**，`fix` 字段就是下一步该做什么。

### `serve`
前台运行服务（等价 `up.cmd`）。一般不用手敲。

## 二、App 管理

### `open <app>`
```bat
phone.cmd open com.apple.TestFlight
phone.cmd open 高德地图          :: 中文名可用：查 data/apps_index.json（61 个已装 App）
phone.cmd open com.autonavi.amap :: bundle id 最稳，生产流程用它
```
- 中文名走静态索引（`data/apps_index.json`），**即时**解析，不用现问手机
- 传 bundle id（带点号）时直接透传
- 名字不认识时，`hint` 会列出相近的名字，别瞎试
- `--wait 2` 会在启动后额外等界面稳定
返回 `{"opened": "高德地图", "bundle": "com.autonavi.amap", "foreground": "com.autonavi.amap", "act_ms": 1240}`

### `apps`
`{"count": 87, "apps": [{"bundleId": "...", "name": "高德地图"}, ...]}` —— 建"中文名→bundle id"映射用，建议缓存到本地 json。

### `app`
当前前台 App：`{"app": {"bundleId": "com.autonavi.amap", "pid": 1234, "name": ""}}`。

### `home`
按下 Home（`press_home`）。**屏幕最底部 34 px 的点按不可靠，一律用它**。

## 三、看

### `shot [--path P] [--b64]`
```jsonc
{"path": "C:\\...\\artifacts\\shot_1794232670.png", "bytes": 1473181, "act_ms": 368}
```
不带 `--path` 自动命名落 `artifacts/`。`--b64` 把 PNG 内联进 JSON（给"能读图但不能读文件"的模型用，注意体积）。
耗时 **0.16~0.43 s**（WDA `/screenshot` 实时帧，不是视频流截屏）。

### `ocr [--limit N] [--grep 关键字]`
```jsonc
{"count": 9, "rows": [
  {"text": "搜索框，输入文字查找地点、公交、地铁", "x": 132.0, "y": 466.0, "type": "StaticText"},
  {"text": "扫一扫", "x": 314.0, "y": 466.0, "type": "Button"}
], "act_ms": 492}
```
- `x/y` = **可直接 tap 的逻辑点**（屏幕 390×844）
- `type`：`Button` / `StaticText` / `TextField` / `Image` / `Other`
- `--grep` 大小写不敏感模糊过滤（**优先用它**，比拉全量再处理省 token）
- `--limit` 默认 60

> 为什么 OCR 有时显示"更多行未显示"：屏上元素上百个（比如键盘），`--limit` 截断了。用 `--grep` 精确定位。

### `find <文本> [--exact]`
只找不点。找到 `ok:true`，没找到 `ok:false`（退出码 1）。适合做断言：
```bat
phone.cmd find 路线偏好 && echo 已经在偏好面板
```

### `tree [--out f.json] [--limit N]`
完整 accessibility 树。不带 `--out` 时返回压平后的行（跟 `ocr` 同构）；带 `--out` 落盘原始树（40~400 KB），用于调试冷门控件。

### `screen`
`{"width":390,"height":844,"scale":3,...}` 设备几何，换机型后先看这个。

## 四、动

### `tap <x> <y>`
绝对坐标点按（逻辑点）。**用完必须 `ocr` 或 `shot` 确认**——布局会漂移。

### `tap-text <文本> [--index N] [--exact]`
按标签点元素，**首选方式**。
```jsonc
{"tapped": {"text": "开始导航", "x": 278.0, "y": 792.0, "type": "Other"}, "act_ms": 720}
```
- 默认模糊匹配，同名多个用 `--index`（0 开始）
- 找不到 → `ok:false`，`hint` 里告诉你有几个候选项
- 实测命中 **0.4~0.7 s**
- 无障碍树挂起（地图类页面）时自动降级 OCR，照样命中

### `tap-if <文本> [--exact]`
点「文本如果出现在屏幕上」，不在就静默跳过（返回 `{"tapped": false}`）。
专为**可能出现的弹窗**设计（权限框、广告「跳过」、更新提示）——用 `tap-text` 硬点会在弹窗没出现时把整个流程打断。
```jsonc
{"cmd": "tap_if", "args": {"text": "不允许"}}   // 麦克风权限弹窗，没有就跳过
```

### `type <文本>`
往**当前焦点**输入框打字。**支持中文**（直接打，不要拼音、不要剪贴板）。
前提：先 `tap` 输入框让它获得焦点，否则会打到别处。

### `field <文本>`
找到屏上第一个 `TextField`，直接设 value（clear + set）。第三方输入法/特殊键盘导致 `type` 失效时用它兜底。

### `swipe <x1> <y1> <x2> <y2> [--seconds 0.3]`
拖动。列表滚动用 `scroll` 更方便。

### `scroll <up|down> [--amount 0.4]`
`amount` 是屏高比例。

## 五、等（比 sleep 快 3~5 倍）

### `wait-text <文本> [--timeout 8] [--exact]`
轮询直到出现，返回 `{"found": {...}, "act_ms": 640}`；超时 `ok:false`。
**典型 0.4~0.8 s 就返回**，而固定 `sleep 2` 永远等满 2 秒。

### `wait-stable [--timeout 8]`
连续两帧一致即返回（画面"停了"）。适合点完之后不确定会跳到哪的场合。

---

## 六、`flow`：一条命令跑完整个流程（最快）

一个进程内顺序执行多步，省掉每步 ~0.6 s 的 Python 启动 + 连接建立。

```bat
phone.cmd flow examples\amap_navigate.json
```

```jsonc
{
  "name": "amap-navigate",
  "steps": [
    {"cmd": "open",  "args": {"app": "com.autonavi.amap"}},
    {"cmd": "tap",   "args": {"x": 132, "y": 466}},
    {"cmd": "type",  "args": {"text": "广州塔"}},
    {"cmd": "tap_text", "args": {"text": "路线", "index": 0}},
    {"cmd": "shot",  "args": {"path": "step2.png"}},
    {"sleep": 1.0}
  ]
}
```

- 可用 `cmd`：`open` `tap` `tap_text` `tap_if` `type` `field` `swipe` `scroll` `shot` `ocr` `wait_text` `wait_stable` `home` `app` `close` `retry`
- 参数写在 `args`（也接受 `with`）
- `{"sleep": 秒}` 是唯一的非 cmd 步骤
- `--keep-going`：某步失败继续跑（结果里标 `ok:false`）
- 返回 `{"flow": "名字", "steps":[{i, cmd, ok, ms}...], "total_ms": N}`

> 高德导航 6 步：分步调用约 15 s，`flow` 里约 9~10 s。

## 七、返回码速查

| 场景 | ok | 退出码 |
|---|---|---|
| 正常 | true | 0 |
| `find` 没找到 / `doctor` 有失败项 | false | 1 |
| 链路起不来、tap-text 找不到目标 | false + `hint` | 1 |
| Ctrl-C | false | 130 |
